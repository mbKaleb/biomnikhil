The short version

You describe a biomedical task in plain English. A Biomni agent (running on {{ provider }}) then works the problem the way an analyst would: it thinks about what to do, writes real Python code, runs it, reads the result, and repeats until it can give you an answer. The terminal-style trace panel on the right shows every one of those moves as it happens.

The agentic loop

Your promptplus any attached files
→
Thinkthe agent plans its next move
→
Write codereal Python, using Biomni's tools & data lake
Answerthe final solution lands in the chat
←
Decidesolved? if not, loop again
←
Observethe code runs; its output feeds back in
think → code → observe … repeated until a solution emerges

Each pass through that loop is one step in the trace panel. Simple questions may finish in one step; a real analysis (load data, clean it, run statistics, plot) usually takes several. Guardrails stop the run if the agent loops without progress or exceeds the step budget.

Reading the trace panel

Open it with the >_ button in the header. What you'll see:

▶ run — "…" A run started. The matching footer shows how it ended: ■ done, ✕ failed, or ⊘ stopped — with the total duration.
STEP N  ·  15:40:42 One pass of the loop, numbered, with the time it arrived — gaps between timestamps tell you where the agent spent its time.
italic text The agent's reasoning — why it's about to do what it does next.
code Python the agent wrote and is about to execute, syntax-highlighted.
output What the code printed. Tables keep their alignment, missing values (NaN) are dimmed, and long outputs collapse behind a "show all" expander. Red-bordered output means the code raised an error — the agent sees it too and usually fixes itself on the next step.
answer The final solution — the same text that appears in the chat.
running code… █ The live status line: what the agent is doing right now. The header shows a ticking elapsed time for the whole run, and a "↓ new output" pill appears if new steps arrive while you've scrolled up to read something.

Where the data comes from

On first run the app downloads the Biomni data lake (~11 GB of curated biomedical reference data — genomes, drug databases, pathway maps) that the agent's tools draw on. Files you upload on the Files tab and attach to a prompt are placed where the agent's code can read them directly.

Good to know

  1. Every chat keeps its full trace — reload the page or reopen a chat and the whole history replays, and an in-flight run reattaches live.
  2. Stop cancels a run between steps; the trace marks it ⊘ stopped.
  3. One task runs at a time — the agent executes real code on this machine, so runs are deliberately serialized.
  4. Errors in red are normal mid-run: the agent reads its own tracebacks and retries. A run only fails if it can't recover.
