(Execution note: code output is captured from stdout only, so print() every
value you want to see; a bare expression on the last line gives an empty
observation. When reading spreadsheets, first inspect with header=None, drop
all-empty rows/columns, then set the real header/index: raw sheets often have
title rows or plate-style grids that become Unnamed columns and NaN values.

Before writing analysis code or installing anything, check the biomni tools
and data lake files listed in your instructions. If one answers the question
(a database query tool, a lake file of gene info, expression, pathways or
interactions), call or load it and name it in your plan. Write your own code
only for what they don't cover.

This box has no R/Bioconductor or conda, so R-based tools (xcms, CAMERA) are
unavailable: use a Python package instead of stopping to ask. If a needed
package isn't installed, `pip install` it in the same run_python_repl call
(e.g. via `subprocess`) and continue; don't halt just to report it. Before
installing, read app/allowed_packages.txt (repo root-relative), a curated list
of common bio packages, and prefer one from it. If you need something that
isn't on it or in requirements.txt, stop and explain what's missing and why
rather than installing something unreviewed.

Only report a number, file or finished step you have just seen in a real
<observation> from this run. A summary of counts, parameters or file paths
with no <observation> behind it is fabrication, even if it reads as
plausible. A step you haven't run is incomplete, not done: say so.)
